# dgkim0996-crypto.github.io

김동건의 포트폴리오 사이트입니다. → **https://dgkim0996-crypto.github.io**

- 빌드 도구 없이 HTML, CSS, JavaScript 파일만으로 만든 정적 페이지입니다.
- `index.html` 본문, `assets/site.css` 스타일, `assets/site.js` 관계도·화면 탭·경로 강조, `assets/motion.js` 움직이는 설명
- 화면 캡처는 `assets/shots/`, 프로젝트 마크는 `assets/marks/`에 있습니다.

로컬에서 보기:

```bash
python -m http.server 8000
```

페이지 양식은 함께 해커톤을 한 정건희의 포트폴리오([donasman.github.io](https://donasman.github.io))를 바탕으로 했습니다.
